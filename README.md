# Student Result Management System

## Objective

Develop and deploy a cloud-based Student Result Management System using a complete DevOps pipeline.

## Technologies Used

- Python Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git & GitHub
- Docker
- Jenkins
- Terraform
- AWS EC2
- Amazon S3
- CloudWatch

## Features

- Admin Login
- Student Login
- Add Student
- Update Student Marks
- View Results
- Docker Deployment
- Jenkins CI/CD Pipeline
- Infrastructure as Code
- AWS Monitoring
